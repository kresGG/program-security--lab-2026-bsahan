\# Політика конфіденційності: БД Агентства нерухомості



\## Дані, що збираються

Система збирає лише ті дані, які реально необхідні для виконання визначених функцій (принцип мінімізації): ПІБ клієнта, номер телефону, дані про нерухомість.



\## Правила доступу та зберігання

Персональні дані доступні лише авторизованим рієлторам. Передавання даних третім сторонам без згоди клієнта заборонено.
