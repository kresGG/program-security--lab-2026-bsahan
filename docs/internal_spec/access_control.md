\# Специфікація керування доступом (Access Control)



\## 1. Обрана модель доступу

Використовується \*\*змішана модель (RBAC + ABAC)\*\*:

\* \*\*RBAC:\*\* Доступ до функцій розмежовується за ролями (`Admin`, `Realtor`).

\* \*\*ABAC:\*\* Доступ до редагування/видалення ресурсів перевіряється за атрибутом власника (`Object.OwnerId == User.Id`).



\## 2. Суб'єкти та ролі

\* \*\*Admin (Адміністратор):\*\* Повний доступ до всіх об'єктів, угод та користувачів\[cite: 32].

\* \*\*Realtor (Рієлтор):\*\* Додавання нових об'єктів, перегляд усіх об'єктів зі статусом "Доступно", редагування/видалення лише ВЛАСНИХ об'єктів\[cite: 32, 33].



\## 3. Матриця прав та правил доступу



| Операція | Суб'єкт | Умова дозволу (Перевірка в коді) |

| :--- | :--- | :--- |

| `CreateObject` | Realtor, Admin | Авторизований користувач |

| `ViewObject` | Realtor, Admin | Будь-який авторизований користувач |

| `EditObject` | Admin | Завжди дозволено |

| `EditObject` | Realtor | `Object.OwnerId == CurrentUser.Id` |

| `DeleteObject` | Admin | Завжди дозволено |

| `DeleteObject` | Realtor | `Object.OwnerId == CurrentUser.Id` |
