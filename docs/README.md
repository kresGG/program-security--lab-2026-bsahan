\# Документація: База даних агентства нерухомості (КПКБЗІ.230299.23.02.10 ПЗ)



\## Призначення та межі системи

Система призначена для автоматизації обліку об'єктів нерухомості, клієнтів та угод. Поза межами системи залишається бухгалтерський та податковий облік.



\## Вимоги (ISO/IEC/IEEE 29148)

\* \*\*Функціональні вимоги:\*\* Система повинна дозволяти рієлтору додавати нові об'єкти, змінювати їхній статус і формувати договори\[cite: 2].

\* \*\*Нефункціональні вимоги:\*\* Час відгуку бази даних при пошуку об'єкта за адресою не повинен перевищувати 2 секунди\[cite: 2].



\## Архітектура (ISO/IEC/IEEE 42010)

Система побудована за клієнт-серверною архітектурою з використанням C# (ADO.NET) для клієнтської частини та MS SQL Server для зберігання даних.
